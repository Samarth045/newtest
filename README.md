# My Money Control

An offline-first personal finance PWA for iPhone and desktop.

## Features
- Dashboard, transactions, budgets and accounts
- Income, expense, investment, EMI, saving, transfer, borrow and payback
- Working edit/delete transaction flow
- Recurring payments with Mark Paid and duplicate protection
- Financial health metrics
- JSON backup/restore and CSV export
- Local browser storage; no financial data is sent to GitHub
- PWA install/offline support

## iPhone
Open the GitHub Pages URL in Safari and use **Share → Add to Home Screen**.

## Data
The repository contains application code only. Financial data stays in the device browser storage unless exported by the user.
